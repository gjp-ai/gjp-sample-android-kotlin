# GJPS Android Feature Lab

A small Kotlin + Jetpack Compose project used for hands-on Android development tuition.

Start with [ANDROID_TUITION.md](ANDROID_TUITION.md). It maps each lesson to the source code and provides exercises that gradually extend this app.

The app demonstrates:

- a splash screen and Activity-based navigation;
- Compose and Material 3 layouts;
- device and Android OS information from platform APIs;
- native `HttpURLConnection` requests with coroutine-based I/O;
- HTTP response display, JSON formatting, headers, and error handling.

Run the baseline checks with `./gradlew assembleDebug` and `./gradlew test`.
